一个用 Python 和 Streamlit 实现的 Enigma machine 玩具模拟器，用于实时实验 Enigma 风格的加密和解密过程。

- 实现了可配置的转子选择、转子初始位置、反射器行为和 plugboard 替换。
- 支持从 5 个预定义转子中选择 3 个组成机器配置。
- 通过 Streamlit 界面实时输入文本并查看加密 / 解密结果。
- 展示当前机器状态，方便检查活跃配置和理解加密过程。
