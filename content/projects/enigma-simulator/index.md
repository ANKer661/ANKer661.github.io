A toy simulator of the historical Enigma machine, built with Python and Streamlit for real-time interaction.

- Implemented configurable rotor selection, rotor initial positions, reflector behavior, and plugboard substitution.
- Supported choosing 3 rotors from 5 available rotor definitions.
- Added real-time encryption and decryption through a Streamlit interface.
- Displayed the current machine state so users can inspect the active configuration.
